# GeoNexus

## Overview

O **GeoNexus** é um plugin para QGIS desenvolvido para auxiliar a análise técnica do CAR por meio do processamento de camadas geográficas, comparação de bases oficiais e verificação espacial de inconsistências.

## Features

*   **Autenticação Segura:** Gerencia o login do usuário e armazena credenciais de forma segura no QGIS.
*   **Seleção de Estado:** Interface intuitiva para seleção de projetos por estado (Amapá e Pará).
*   **Download Automático:** Baixa e abre projetos do Google Drive automaticamente.
*   **Integração com GeoServer:** Conexão direta com serviços WMS/WFS.

## Requirements

*   **QGIS Version:** 3.40 ou superior.
*   **Dependências:** `requests`, `psycopg2`.
